# Galle Builder

Catálogo de peças, banco de ideias e desafios para os kits de robótica do Colégio Galle
(SPIKE Prime, SPIKE Essential e EV3), feito para os iPads do laboratório.

- Site estático, sem login e sem coleta de dados.
- Lista de peças e imagens: [Rebrickable](https://rebrickable.com).
- LEGO® é marca registrada do Grupo LEGO, que não patrocina nem endossa este projeto.
